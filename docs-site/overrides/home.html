Storage that keeps working when a server fails.

Haify turns the disks in your own Linux servers into shared storage for files, virtual machines, containers and databases. Lose a server and your applications keep their data and carry on.

Why Haify

No single point of failure
Every write is on more than one server, and services move on their own when one fails.
Your hardware
Ordinary Linux servers and their local disks. No storage array, no special network.
Simple to run
Manage it from a web UI, the command line or an AI assistant.
Problems found early
Alerts in your chat when something degrades, and a daily check that says how to fix it.
Open source
Apache 2.0, free to use, change and run in production.

From disks to a shared folder

Four commands, once Haify is installed.

  1. Add your servers.

    haify node register --name node1 --address 192.0.2.11 haify node register --name node2 --address 192.0.2.12

  2. Give Haify a disk on each one.

    haify pool create --name pool0 --type lvm-thin --nodes node1,node2 --devices /dev/sdb

  3. Create a 10 GiB volume kept on both.

    haify resource create --name data --port 7001 --size 10G --nodes node1,node2 --pool pool0

  4. Share it over NFS.

    haify gateway nfs create --resource data --service-ip 192.0.2.200/24 --export-path /data
